# Herança

O conceito de herança visa resolver o problema de generalização e especialização.


A classe Semfio é uma especialização de Telefone. 
Tem acesso aos mesmos tipos de atributo e metodos implementados na superclasse.

Uma classe especialista, pode sobreescrever os métodos da superclasse.

 Associação de herança pode ser lida como "*é um*". Essa pergunta é um jeito de verificar a validade da implementação de uma herança:
- Celular é um Telefone ? sim
- Semfio é um Telefone ? sim
- Celular é um Semfio ? nao
- Semfio é um Celular ? nao
